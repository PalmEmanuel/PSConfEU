## Treasure Hunting in Azure with KQL as Your Map

In Azure, understanding the full landscape of your resources is key to making informed decisions.

What role assignments do we have? What are the most recent changes in production, and who made them? Are there any differences between our environments, and in that case which ones?

Kusto Query Language (KQL) combined with Azure Resource Graph provides a fast, powerful way to explore, analyze, and gain insights across your cloud environment.

We'll walk through practical use cases, real-world examples, and an overview of KQL so you can navigate your Azure environment with confidence.

In hands-on demos we will also utilize bARGE, an extension for Visual Studio Code which boosts our ability to query Azure directly from our development environment.
